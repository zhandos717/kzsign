# Ручная проверка KZSign перед использованием

Автотесты: `npm test` (юнит) и `npm run build && npm run test:e2e` (Chromium с расширением).

## Установка

1. `npm run build`
2. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `dist/`.
3. Значок KZSign → «Добавить ключ» → свой `.p12` и пароль.

## Сайты

- [ ] egov.kz — вход по ЭЦП: появляется окно KZSign с `egov.kz`, после подписи вход выполнен.
- [ ] goszakup.gov.kz — вход по ЭЦП.
- [ ] Внутренний сайт команды №1: ________
- [ ] Внутренний сайт команды №2: ________
- [ ] На каждом сайте в окне подтверждения выделен правильный домен.

## Режимы

- [ ] Настоящий NCALayer запущен, режим «Только настоящий NCALayer» → подпись идёт через NCALayer, окна KZSign нет.
- [ ] Режим «Авто», ключи в KZSign есть → подписывает KZSign.
- [ ] Режим «Авто», ключей нет, NCALayer запущен → подписывает NCALayer.

## Подпись файла

- [ ] Popup → «Подписать файл» → скачался `<имя>.cms`; проверка в NCANode (`docs/decisions/0002`) или на ezsigner.kz → VALID.

## Известные ограничения v1

- Нет XML-подписи (`signXml`, `format: "xml"`): сайты, которым она нужна, получат «не поддерживается».
- Нет eGov QR (фаза 2).
- Подпись TSA на метке времени проверяет верификатор, а не расширение.
