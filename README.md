# KZSign

Расширение Chrome (Manifest V3) для подписи ЭЦП НУЦ РК прямо в браузере, без NCALayer. Страница обращается к привычному интерфейсу NCALayer, а подпись выполняет расширение с ключом `.p12`, который пользователь добавил сам.

## Возможности

- CMS-подпись (attached и detached) по ГОСТ 34.310-2004 и RSA, с меткой времени (TSP `tsp.pki.gov.kz`).
- XML-подпись (XMLDSig) в формате НУЦ.
- Совместимость с протоколом NCALayer: `basics`, `signXml`, `signXmls` и др.; проверено на `ncalayer-js-client`.
- Окно подтверждения с доменом сайта, список доверенных сайтов, запоминание выбора.
- Загрузка ключа прямо из окна подписи.
- Результаты подписи проверены внешним NCANode.

## Установка

```bash
npm install
npm run build
```

В `chrome://extensions` включите «Режим разработчика» → «Загрузить распакованное» → папка `dist/`. Затем значок KZSign → «Добавить ключ» → `.p12` и пароль.

## Разработка

| Команда | Что делает |
| --- | --- |
| `npm run build` | сборка в `dist/` (esbuild) |
| `npm test` | юнит-тесты (vitest) |
| `npm run typecheck` | проверка типов |
| `npm run test:e2e` | e2e в Chromium с расширением (Playwright), нужна предварительная сборка |
| `npm run icons` | перерисовка иконок |

Подпись из командной строки:

```bash
npx tsx scripts/sign-file.ts <key.p12> <пароль> <файл> [attached|detached] [--tsp]
npx tsx scripts/sign-xml.ts
```

## Структура

- `src/core` — криптография и форматы: p12, CMS, XMLDSig, TSP, разбор сертификата.
- `src/shims`, `src/page` — подмена NCALayer на странице (MAIN world).
- `src/content` — мост между страницей и расширением.
- `src/sw` — service worker.
- `src/ui`, `static` — popup и окно подтверждения.
- `docs/decisions` — архитектурные решения (ГОСТ-движок, внешняя проверка, XMLDSig).
- `docs/manual-checklist.md` — ручная проверка перед использованием.

## Безопасность

Ключ и пароль остаются в браузере пользователя. Каждая подпись требует подтверждения в окне с указанием домена сайта, если сайт не добавлен в доверенные.
